LINEAGE W PC 혈맹 채팅 인식기

Windows용 1차 OCR 미리보기 프로그램입니다. 선택한 화면 영역에서 초록색 글자 줄만 추출합니다.

설치:
1. Windows에 Python 3.11 이상 설치
2. Tesseract OCR for Windows 설치 시 Korean(한국어) 언어 데이터 포함
3. 명령 프롬프트에서 pc-chat-capture 폴더로 이동
4. 다음 명령 실행:
   py -m pip install -r requirements.txt
   py pc_chat_capture.py

보탐봇 연결:
1. 보탐봇 로그인 후 채팅 자동인식 설정 열기
2. 게임 캐릭터 닉네임을 보탐봇 회원 계정에 연결
3. Windows PC 기기를 등록하고 인증키 복사
4. 이 프로그램에 인증키 입력
5. 채팅창 영역 선택 후 OCR 미리보기 확인
6. 정확한 작성자/명령 인식이 확인되기 전에는 자동 전송을 켜지 마세요.

안전:
- 게임 내부 메모리, 패킷, 파일에 접근하지 않고 화면 픽셀만 캡처합니다.
- 캡처/자동화가 게임 및 원격 접속 서비스 약관에 허용되는지 확인해야 합니다.
- 현재는 "닉네임: 컷 보스 20:35" 형식이 OCR 한 줄에 잡힐 때만 전송합니다. 실제 채팅 레이아웃에 맞춘 발신자 추출은 미리보기 결과를 확인한 뒤 조정해야 합니다.
- OCR 반복 전송은 이 프로그램 실행 중 기기별로 억제합니다. PC와 스마트폰 사이의 완전한 전역 중복 제거는 실제 채팅 고유 ID/메시지 시각을 확보한 뒤 보강해야 합니다.
